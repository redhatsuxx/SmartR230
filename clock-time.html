Setting the Clock
Set your SL R230's dashboard clock using the SmartR230 emulator
← Back to home

Overview

Alongside masking BCM fault messages, the SmartR230 emulator can also be used to set the dashboard clock on your Mercedes-Benz SL R230 - handy after a battery disconnect, module swap, or if the clock has simply drifted.

Normally this would require a dealer-level diagnostic tool. The SmartR230 emulator lets you do it directly, without any extra equipment.
